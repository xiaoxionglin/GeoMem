# geomem-paper

Manuscript, reports, and Obsidian-facing writing context for GeoMem.

## Owns

- Structured manuscript drafts.
- Iteration reports and reviewer-style evaluations.
- Paper-facing figure embeds.
- Literature context used directly in the manuscript.

## Figure Links

Generated figures are owned by `geomem-experiments`. Markdown figure links in this subproject should use:

```text
../geomem-experiments/figures/<figure-name>.svg
```
