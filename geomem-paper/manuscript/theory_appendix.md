# Appendix A: Formal Statements And Proofs

This appendix gives the formal statements used by the current GeoMem draft. The theory is scoped to the deterministic shortest-path regime instantiated by the current formal diagnostics and supervised navigation tasks. It formalizes memory **content**; it does not assert that a particular neural mechanism learns the required content with minimal data or energy.

## A.1 Deterministic Goal-Navigation Tasks

### Definition A.1. Goal-Navigation Task

A deterministic goal-navigation task is

$$
\mathcal{T} = (S, A, \operatorname{valid}, \delta, z, G, s_0)
$$

where:

- `S` is a finite latent state set;
- `A` is a finite action-label set;
- `valid(s)` is the set of actions available from state `s`;
- `delta(s, a)` is defined for `a in valid(s)`;
- `z: S -> O` is the observation map;
- `G` is a set of goals;
- `s0` is the fixed start state when histories are generated from a root.

For each goal `g in G`, the navigation graph may augment the forward transition graph with reverse action labels, as the trace diagnostics do with undo actions. Let `d_g(s)` be shortest-path distance from `s` to `g` in the graph used for goal `g`.

### Definition A.2. Feasible Histories And Memory

A feasible history is

$$
h_t = (o_0, a_0, o_1, \ldots, a_{t-1}, o_t)
$$

generated by states `s0, ..., st` with `o_i = z(s_i)`, `a_i in valid(s_i)`, and `s_{i+1} = delta(s_i, a_i)`. Write `s(h_t) = s_t`.

A memory representation is a map

$$
f: H \to M
$$

from feasible histories to memory states. An online mechanism for `f` also has an update

$$
m_{t+1} = U(m_t, a_t, o_{t+1})
$$

The results below concern the compression map `f`. They do not assume a specific RNN, reservoir, or hippocampus-inspired implementation of `U`.

### Definition A.3. Goal-Conditioned Optimal Actions

For a non-goal history `h` and goal `g`, define

$$
A^*(h,g) = \{a \in \operatorname{valid}_g(s(h)) : d_g(\delta_g(s(h),a)) = d_g(s(h)) - 1\}
$$

The subscript `g` allows the policy graph to include goal-evaluation actions such as reverse edges. The set notation allows shortest-path ties.

### Definition A.4. Goal-Conditioned Policy Sufficiency

A memory representation `f` is goal-conditioned policy-sufficient for `G` if every nonempty memory-goal class has at least one action that is optimal for every history in that class:

$$
\forall m \in M,\; \forall g \in G,\qquad
\bigcap_{h:f(h)=m} A^*(h,g) \neq \varnothing
$$

whenever the intersection ranges over non-goal histories with defined optimal actions.

### Lemma A.1. Common-Action Characterization

`f` is goal-conditioned policy-sufficient if and only if there exists a readout `pi: M x G -> A` such that `pi(f(h), g) in A*(h, g)` for every evaluated non-goal history and goal.

#### Proof

Assume policy sufficiency. For every memory-goal pair `(m, g)` with evaluated histories, choose any action from

$$
\bigcap_{h:f(h)=m} A^*(h,g)
$$

This action exists by Definition A.4. Define `pi(m, g)` to be that action on evaluated classes and arbitrarily elsewhere. For each history `h` in the class, the chosen action lies in `A*(h, g)`, so the readout is optimal for all represented histories.

Conversely, assume such a readout exists. Fix any evaluated class `(m, g)`. For every history `h` with `f(h)=m`, the same action `pi(m, g)` lies in `A*(h, g)`. Hence it lies in the intersection of all optimal-action sets in that class. The intersection is nonempty, so `f` is policy-sufficient. QED.

### Definition A.5. Markov Sufficiency For A Memory

A memory representation with observations is Markov-sufficient for the valid dynamics if there exists an update `U` such that for every feasible history `h` and valid action `a`,

$$
f(h\,a\,z(\delta(s(h),a))) = U(f(h), a, z(\delta(s(h),a)))
$$

Equivalently, histories that give the same update input `(f(h), a, o')` must require the same next memory.

## A.2 Aliasing Lemmas

### Lemma A.2. Policy Conflict

If for some goal `g` there are histories `h` and `h'` with

$$
f(h) = f(h')
$$

and

$$
A^*(h,g) \cap A^*(h',g) = \varnothing
$$

then `f` is not goal-conditioned policy-sufficient.

#### Proof

Let `m = f(h) = f(h')`. If `f` were policy-sufficient, Definition A.4 would require a common action in the intersection of the optimal-action sets of every history in the class `(m, g)`. The pair `h, h'` already has empty intersection, so the full class intersection is empty. This contradicts policy sufficiency. QED.

### Lemma A.3. Markov Conflict

Suppose histories `h` and `h'` satisfy

$$
f(h) = f(h') = m
$$

Let `a` be valid from both terminal states and suppose the next observations agree:

$$
z(\delta(s(h),a)) = z(\delta(s(h'),a)) = o'
$$

If the required next memories differ,

$$
f(h\,a\,o') \neq f(h'\,a\,o')
$$

then `f` is not Markov-sufficient.

#### Proof

If `f` were Markov-sufficient, Definition A.5 would give an update `U` with

$$
f(h\,a\,o') = U(m,a,o')
$$

and

$$
f(h'\,a\,o') = U(m,a,o')
$$

Both required next memories would equal the same update output, contradicting their assumed inequality. QED.

### Diagnostic Consequence

The current diagnostics have these formal interpretations:

- observation ambiguity shows that a proposed observation or memory merges latent states;
- transition ambiguity supplies witnesses to Lemma A.3 for the tested transition target;
- policy-set ambiguity detects failure to preserve the full tied optimal-action set;
- strict policy conflict requires empty common optimal-action intersection as in Lemma A.2.

Policy-set mismatch is stronger evidence than state aliasing but not identical to policy insufficiency when tied optimal-action sets still share an action.

### Lemma A.4. Goal-Family Separation

Let a representation `f` merge histories `h` and `h'`. If a goal family `G` contains at least one goal `g` for which

$$
A^*(h,g) \cap A^*(h',g) = \varnothing
$$

then `f` is not policy-sufficient for the whole goal family `G`.

More generally, suppose a goal family is separating for a set of latent states in the sense that every pair of distinct states merged by `f` is exposed by at least one goal with disjoint optimal-action sets. Then `f` cannot be policy-sufficient on that state set unless it stops merging those separated states.

#### Proof

The first statement is Lemma A.2 applied to the separating goal in `G`. Policy sufficiency is required for every goal in the family, so failure on one goal is failure for the family.

For the second statement, assume `f` merges a separated pair of distinct states represented by histories `h` and `h'`. By the separating assumption, some goal in the family gives disjoint optimal-action sets for that pair. The first statement applies, so the merged representation is not policy-sufficient. Therefore a policy-sufficient representation on a separating family cannot retain such a merge. QED.

### Lemma A.5. State-Revealing Observations Remove History Demand For Current-State Policies

Suppose the current observation map `z` is injective on the evaluated latent states and every optimal-action set `A*(h, g)` depends only on current latent state `s(h)` and goal `g`. Then current-observation memory

$$
f_{\mathrm{obs}}(h) = z(s(h))
$$

is goal-conditioned policy-sufficient.

#### Proof

Fix an observation memory value `o` and goal `g`. Injectivity of `z` implies that all evaluated histories with `f_obs(h) = o` have the same current latent state `s`. By assumption, their optimal-action sets depend only on `(s, g)`, so all histories in the class have the same nonempty set `A*(s, g)`. The intersection over the class is that set itself. Definition A.4 gives policy sufficiency. QED.

This lemma formalizes the negative control that path noncommutativity alone does not force history memory when the current observation already identifies the policy-relevant state.

## A.3 Fully Commutative Trace Tasks

### Definition A.6. Trace Quotient

Let `Sigma` be a finite generator alphabet. A symmetric irreflexive commutation relation `I` contains pairs `{a, b}` whose adjacent occurrences may swap. The trace equivalence `~_I` on words in `Sigma*` is generated by

$$
uabv \sim_I ubav
$$

whenever `{a, b} in I`.

The trace state of a word `w` is its equivalence class `[w]_I`. The current bounded trace tasks retain classes with word length at most depth `D`. A forward append action `a` is valid only below depth `D`. The shortest-path policy graph augments valid forward appends with reverse undo edges.

Define the count vector

$$
c(w) = (n_a(w))_{a \in \Sigma}
$$

### Proposition A.1. Count Sufficiency In The Fully Commutative Trace Limit

If every distinct pair of generators commutes, then the count vector is a bijection between bounded trace states `[w]_I` with `|w| <= D` and nonnegative count vectors with total count at most `D`. It is therefore Markov-sufficient for the valid append dynamics and for the induced append-plus-undo navigation graph.

#### Proof

We first prove that count vectors identify trace classes.

Let `w` and `w'` have the same count vector. Because every distinct pair of generators commutes, adjacent swaps may reorder any word into a fixed sorted normal form containing `c_a(w)` copies of each generator `a` in a chosen alphabet order. The words `w` and `w'` sort to the same normal form because their counts agree. Hence `w ~_I w'`, so they are the same trace state.

Conversely, if `w ~_I w'`, the equivalence is a finite composition of adjacent swaps. Every swap preserves the number of occurrences of each generator. Therefore `c(w) = c(w')`. Count vectors and trace states are in one-to-one correspondence.

Now fix a bounded trace state with count vector `c`. If its depth `sum_a c_a` is below `D`, appending generator `b` is valid and changes the count vector to `c + e_b`, where `e_b` is the unit vector for generator `b`. This update depends only on `c` and `b`, not on a representative word. At depth `D`, forward append actions are invalid in the valid-action dynamics, so no boundary self-loop must be represented.

For the navigation graph, an undo edge labeled `undo_b` exists precisely when the chosen predecessor removes one occurrence of the last appended `b` in some representative. In the fully commutative quotient this predecessor class has count vector `c - e_b` whenever `c_b > 0`. If `c_b = 0`, no such predecessor exists. Thus valid undo transitions also depend only on `c` and the undo label.

Counts therefore identify the bounded trace state and determine every valid one-step transition used by the navigation graph. They are Markov-sufficient. QED.

### Corollary A.1. Policy Sufficiency In The Fully Commutative Trace Limit

For any goal family on the bounded append-plus-undo graph whose optimal actions depend only on the current graph state, count memory is goal-conditioned policy-sufficient.

#### Proof

By Proposition A.1, the count vector identifies the current graph state exactly. Any optimal action set computed from that graph state and goal is therefore a function of counts and goal. The common-action condition holds trivially within each count-goal class because the class contains only one graph state. QED.

## A.4 Additive Local-Metric Proxies

### Proposition A.2. Additive Memories Merge Same-Multiset Histories

Let

$$
m(w) = \sum_{t=1}^{|w|} \phi(a_t)
$$

for a map `phi` from action labels to an additive vector space. If words `w` and `w'` contain the same multiset of action labels, then `m(w) = m(w')`.

If those merged histories have disjoint optimal-action sets for some goal, no readout from `m` is policy-sufficient.

#### Proof

Enumerate the action labels in `w` and `w'`. Equal multisets mean there is a permutation of positions that maps the labels of `w` to the labels of `w'`. Since addition in the codomain is commutative and associative,

$$
\sum_t \phi(a_t) = \sum_t \phi(a'_t)
$$

Hence the additive memory merges the histories. If their optimal-action sets are disjoint for a goal, Lemma A.2 applies to the memory representation `m`. QED.

### Example A.1. Free-History Counterexample

Consider a free append tree with forward generators `A`, `B`, and `X`, root `epsilon`, and reverse undo actions. Let the goal be the word `ABX`.

The histories reaching `AB` and `BA` have the same action multiset `{A, B}`. Every additive action memory gives

$$
m(AB) = \phi(A) + \phi(B) = \phi(B) + \phi(A) = m(BA)
$$

From `AB`, the unique shortest first action to goal `ABX` is append `X`.

From `BA`, any path to `ABX` must first leave the `BA` branch. The unique first action on a shortest path is `undo_A`, which returns from `BA` to `B`; then the path undoes `B` and appends `A`, `B`, and `X`. Appending a symbol or undoing `B` first is invalid or strictly longer at `BA`. Therefore

$$
A^*(AB, ABX) = \{X\}
$$

$$
A^*(BA, ABX) = \{\operatorname{undo}_A\}
$$

The sets are disjoint. Additive memory is not policy-sufficient on this task. This example proves the failure mode without claiming that every noncommutative task exposes it for every goal.

## A.5 Mixed Metric-Route Tasks

### Definition A.7. Policy Factorization

A mixed navigation task has latent state `s = (x, q)` where `x` is locally metric state and `q` is route, branch, cue, portal, or latent-context state. Let

$$
f_x: H \to M_x,
\qquad
f_q: H \to M_q
$$

be metric and residual summaries.

The goal-conditioned policy quotient factorizes through `(f_x, f_q)` when for every goal `g` there is a nonempty action map `P_g` such that

$$
A^*(h,g) = P_g(f_x(h), f_q(h))
$$

for every evaluated non-goal history `h`.

This condition says that the pair of summaries preserves all policy-relevant local and residual distinctions. It allows `f_q` to be an ordered history, graph identity, clone-state assignment, belief-like state, or another residual memory.

### Proposition A.3. Hybrid Sufficiency Under Metric-Route Factorization

If the policy quotient factorizes through `(f_x, f_q)`, then

$$
f_{\mathrm{hybrid}}(h) = (f_x(h), f_q(h))
$$

is goal-conditioned policy-sufficient.

If there are histories `h` and `h'` with the same metric summary `f_x(h) = f_x(h')` and disjoint optimal-action sets for some goal, then the metric-only memory `f_x` is not policy-sufficient.

#### Proof

Fix a hybrid memory value `(m_x, m_q)` and goal `g`. Any history `h` in this class has `f_x(h) = m_x` and `f_q(h) = m_q`. By policy factorization,

$$
A^*(h,g) = P_g(m_x, m_q)
$$

for every evaluated history in the class. The set `P_g(m_x, m_q)` is nonempty by assumption, so the intersection of all optimal-action sets in the hybrid class equals that same nonempty set. Definition A.4 yields policy sufficiency.

For the metric-only statement, the two histories lie in the same `f_x` class. Their optimal-action sets are disjoint, so Lemma A.2 yields policy insufficiency of `f_x`. QED.

### Corollary A.2. Hybrid Compression Relative To Raw History

Let `H_eval` be the evaluated finite history set. Let raw-history memory be the identity map on `H_eval`, and let memory cardinality be

$$
C_{\mathrm{card}}(f) = |f(H_{\mathrm{eval}})|
$$

If at least two distinct evaluated histories have the same hybrid memory, then

$$
C_{\mathrm{card}}(f_{\mathrm{hybrid}}) < C_{\mathrm{card}}(f_{\mathrm{raw}})
$$

#### Proof

Raw-history memory is injective on `H_eval`, so `C_card(f_raw) = |H_eval|`. The hybrid image has at most `|H_eval|` states. If two distinct histories share a hybrid memory value, the hybrid map is not injective and its image has strictly fewer than `|H_eval|` elements. QED.

This is only a compression result relative to raw history. Proving that a hybrid is lowest-cost among architecture classes requires specifying the cost and comparison class.

## A.6 Delayed Sparse Evidence

### Definition A.8. Balanced Cue-Gap Decision

A balanced cue-gap decision samples cue `q in {L, R}` with probability `1/2`. The correct decision action sets at time `D` are disjoint:

$$
O_L \cap O_R = \varnothing
$$

For a finite memory window of length `H < D`, assume the action-observation window available at the decision is cue-independent:

$$
W_H(L) = W_H(R)
$$

This captures a cue shown before the gap and blanked later observations and action features that do not leak cue identity.

### Proposition A.4. Finite Windows Shorter Than The Cue Gap Are Chance-Limited

Under Definition A.8, every deterministic decision rule using only `W_H` has balanced cue-dependent accuracy at most `1/2`. The same bound holds for randomized rules in expectation over their internal randomness.

#### Proof

First consider a deterministic rule `r`. Since the windows are identical,

$$
r(W_H(L)) = r(W_H(R)) = a
$$

The optimal action sets for the two cues are disjoint. Therefore `a` can lie in at most one of `O_L` and `O_R`. The rule is correct on at most one of the two equiprobable cue conditions, so its balanced accuracy is at most `1/2`.

Now consider a randomized rule. Condition on one realization of its internal randomness. The conditioned rule is deterministic, so the preceding argument bounds its accuracy by `1/2`. Averaging over internal randomness cannot increase the bound. QED.

### Scope Of Proposition A.4

The bound applies to explicit finite windows and structured states whose observable span is shorter than the cue-decision gap. It does not forbid a recurrent mechanism with a persistent hidden variable from storing the cue across the gap. Such a mechanism is tested empirically rather than ruled out by this window theorem.
