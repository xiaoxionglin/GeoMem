# Formal Theory Module

## Role

This module is the paper-grade formal package for GeoMem. It formalizes the deterministic shortest-path regime used by the current diagnostics and supervised tasks. The primary control criterion is **goal-conditioned policy sufficiency**. Markov sufficiency is a supporting criterion that explains when a proposed memory fails to define a task state before policy learning is considered. Full proofs are in `../manuscript/theory_appendix.md`.

The formal package is deliberately narrow:

- it defines task-relevant history compression for the current paper;
- it proves order collapse in the fully commutative trace limit;
- it shows why additive local-metric proxies cannot recover required order distinctions;
- it states the hybrid result for factorized local metric and route/context variables;
- it proves the finite-span cue-gap bound used by the delayed navigation sweep.

It does not prove a universal optimality theorem for biological memory systems or learned recurrent mechanisms.

## 1. Deterministic Goal-Navigation Tasks

### Definition 1. Task

A deterministic goal-navigation task is

```text
T = (S, A, valid, delta, z, G, s0)
```

where:

- `S` is a finite latent state set;
- `A` is a finite action set;
- `valid(s)` is the set of actions available from state `s`;
- `delta: S x A -> S` is the transition map on valid actions;
- `z: S -> O` is the observation map;
- `G` is a set of goals;
- `s0` is the start state when histories are generated from a fixed root.

For each goal `g in G`, let `d_g(s)` be shortest-path distance from `s` to `g` in the goal-navigation graph. Undo actions may be included explicitly in that graph, as in the current trace policy diagnostics.

### Definition 2. Histories And Memory

A feasible action-observation history is

```text
h_t = (o0, a0, o1, ..., a_{t-1}, ot)
```

generated by a latent state path `s0, ..., st` with `o_i = z(s_i)` and `s_{i+1} = delta(s_i, a_i)`. Let `s(h_t) = s_t`.

A memory representation is a map

```text
f: H -> M
```

from feasible histories to memory states. An online implementation additionally admits an update rule

```text
m_{t+1} = U(m_t, a_t, o_{t+1}).
```

The theorem statements below concern memory content `f`. Mechanism-level experiments ask whether an RNN, reservoir, or structured sequence generator can realize and learn such content.

### Definition 3. Goal-Conditioned Optimal Actions

For a non-goal state reached by history `h` and goal `g`, define

```text
A*(h, g) = {a in A_g(h): d_g(delta(s(h), a)) = d_g(s(h)) - 1},
```

where `A_g(h)` is the set of valid navigation actions considered for that goal graph. The set notation handles shortest-path ties.

### Definition 4. Policy Sufficiency

A memory representation `f` is goal-conditioned policy-sufficient for `G` if every memory-goal class admits at least one action that is optimal for every feasible history in the class:

```text
for all m in M, g in G:
    intersection_{h: f(h)=m} A*(h, g) is nonempty
```

whenever the class contains non-goal histories with defined optimal actions.

Equivalently, there exists a goal-conditioned memoryless readout `pi(m, g)` that chooses a shortest-path optimal action for every history represented by `m`.

### Definition 5. Strong Policy-Set Preservation

A stronger property is

```text
f(h) = f(h') implies A*(h, g) = A*(h', g)
```

for every tested goal. The current policy-ambiguity diagnostic detects violations of this stronger policy-set preservation. Policy-set mismatch is a useful diagnostic, but exact policy insufficiency requires that no common optimal action remains in the merged class.

### Definition 6. Markov Sufficiency

A memory representation `f` is Markov-sufficient for the valid transition dynamics if there exists a deterministic update map on represented task states such that

```text
f(h) = f(h') and z(delta(s(h), a)) = z(delta(s(h'), a))
```

imply the same next represented memory after action `a`, for every action valid from both histories. In the latent-state diagnostics, a simpler sufficient witness of failure is used: if histories with the same proposed memory and same valid action have distinct latent successors that the representation does not merge into one next memory state, then that memory is not a Markov state for the latent task transition.

## 2. Supporting Lemmas

### Lemma 1. Policy Conflict

If `f(h) = f(h')` for some goal `g` and

```text
A*(h, g) cap A*(h', g) = empty,
```

then `f` is not goal-conditioned policy-sufficient for `G`.

**Proof.** A readout using only `(f(h), g)` must choose the same action for both histories. No action is optimal for both merged histories, so every such readout is suboptimal on at least one of them. QED.

### Lemma 2. Markov Conflict

If two histories share memory `m = f(h) = f(h')`, admit the same valid action `a`, and require distinct next memory states

```text
f(h a z(delta(s(h), a))) != f(h' a z(delta(s(h'), a))),
```

then no deterministic memory-state transition `U(m, a, o')` can update both histories correctly when the next observation supplied to the update is also identical.

**Proof.** The update receives the same arguments on both histories and must return one next memory state. The required next memory states differ. QED.

### Lemma 3. Goal-Family Separation

If a goal family contains a goal that gives disjoint optimal-action sets for two histories merged by `f`, then `f` is not policy-sufficient for the goal family. A goal family that separates every merged latent-state pair therefore forces any policy-sufficient representation to preserve those exposed distinctions.

**Proof summary.** Policy sufficiency must hold for every goal in the family. A separating goal supplies the Policy Conflict hypothesis. Appendix Lemma A.4 gives the full proof.

### Lemma 4. State-Revealing Observation Control

If current observations identify the evaluated latent state and the goal policy depends only on current state and goal, current-observation memory is policy-sufficient even when latent paths are noncommutative.

**Proof summary.** Injective observations make every observation-goal class a single current state for policy purposes. Appendix Lemma A.5 gives the full proof.

### Diagnostic Relation

- Observation ambiguity shows that a proposed observation or memory merges latent states.
- Transition ambiguity supplies Markov-conflict witnesses.
- Policy-set ambiguity shows that merged histories do not preserve shortest-path optimal-action sets.
- A stricter policy-conflict diagnostic should count classes whose common optimal-action intersection is empty.

## 3. Trace Geometry And Additive Metric Proxies

### Definition 7. Trace Tasks

Let `Sigma` be a finite action alphabet. A commutation relation `I` specifies unordered action pairs that may swap when adjacent. The trace state of a word `w in Sigma*` is its equivalence class under swaps of commuting adjacent symbols.

The current trace tasks use canonical representatives of those classes up to a maximum append depth `D`. Valid append actions add one symbol below depth `D`; the navigation policy graph also contains undo edges back to predecessor trace states.

Define the count map

```text
c(w) = (n_a(w))_{a in Sigma}.
```

Counts are the formal abelian local-metric proxy in the trace experiments.

### Proposition 1. Count Sufficiency In The Fully Commutative Trace Limit

If every pair of generators in `Sigma` commutes, then the count map is a bijection between trace states of depth at most `D` and nonnegative count vectors with total count at most `D`. Therefore count memory is Markov-sufficient for the valid append dynamics and the induced undo navigation graph.

**Proof summary.**

1. In a fully commutative quotient, any two words with the same symbol counts are related by adjacent swaps, so they are the same trace state.
2. Words with different counts cannot be related by swaps because swaps preserve counts.
3. A valid append of action `a` maps count vector `c` to `c + e_a` below the depth boundary. At the depth boundary the action is invalid under the valid-action dynamics.
4. An undo edge for `a` exists exactly when `c_a > 0` and maps `c` to `c - e_a`.

Counts therefore identify the trace state and all valid one-step navigation transitions. Appendix Proposition A.1 gives the full proof.

**Paper interpretation.** This is an exact order-collapse control. It justifies the count result in the fully commuting trace condition. It does not assert that biological path integration is literally action counting.

### Proposition 2. Additive Memories Cannot Recover Required Order Distinctions

Let an additive action memory be

```text
m(w) = sum_t phi(a_t)
```

for an action embedding `phi`. For any two words `w` and `w'` with the same action multiset,

```text
m(w) = m(w').
```

If a goal task contains same-multiset histories `h_w` and `h_{w'}` whose optimal-action sets have empty intersection for some goal, then no policy readout from `m` is policy-sufficient for that task.

**Proof summary.** Addition is commutative, so permutations of the same embedded actions have identical sums. The memory merges the two histories. Lemma 1 applies when the merged histories require incompatible optimal actions. Appendix Proposition A.2 gives the full proof.

**Constructive counterexample.** In a free append tree with generators `A`, `B`, and `X`, states `AB` and `BA` have the same counts and the same additive memory. Goal `ABX` lies one append step from `AB`, while the shortest route from `BA` first undoes `A`. The optimal action sets are disjoint, so the count or additive memory cannot choose both correctly from the merged state.

**Paper interpretation.** A vector-like local summary can be exact for local quotient structure and still fail when residual route order is policy-relevant.

## 4. Mixed Metric-Route Tasks

### Definition 8. Factorized Metric-Route Task

A mixed task has latent state

```text
s = (x, q)
```

where:

- `x in X` is a local metric state updated compositionally by local actions;
- `q in Q` is route, branch, cue, portal, or latent-context state;
- current observations may reveal `x` while aliasing `q`;
- the optimal-action set for goal `g` depends only on a metric summary `mu(x)` and a residual summary `rho(q, h)`.

The task-relevant quotient factorizes when there are summaries

```text
mx = f_x(h), mq = f_q(h)
```

such that:

1. `mx` is sufficient for the local metric factor needed by policy;
2. `mq` is sufficient for the residual route/context factor needed by policy;
3. for every goal, `A*(h, g)` depends only on `(mx, mq, g)`.

### Proposition 3. Hybrid Sufficiency Under Metric-Route Factorization

If a mixed task satisfies Definition 8, then the hybrid memory

```text
f_hybrid(h) = (f_x(h), f_q(h))
```

is goal-conditioned policy-sufficient.

If there exist histories with the same metric summary `f_x` but residual states requiring incompatible optimal actions, then the metric-only memory `f_x` is not policy-sufficient.

**Proof summary.** By factorization, all histories with the same hybrid memory and goal have the same policy-relevant local and residual summaries, so they admit the same optimal-action information. A goal-conditioned readout over `(f_x, f_q, g)` can choose an action from the common optimal set. If `f_x` alone merges two histories whose residual factors produce disjoint optimal-action sets, Lemma 1 gives metric-only insufficiency. Appendix Proposition A.3 gives the full proof.

### Corollary 3.1. Compression Relative To Raw History

Let `C_card(f)` be the number of memory states realized by a representation on the feasible history set. If many distinct histories share the same policy-relevant `(f_x, f_q)`, then

```text
C_card(f_hybrid) < C_card(f_raw_history).
```

Thus hybrid memory can be sufficient while compressing raw history. A stronger claim that it is the lowest-cost architecture requires a cost model and comparison class.

**Paper interpretation.** This is the formal version of the local-room/global-route narrative. The room-graph tasks are the navigation-facing empirical family for this result.

## 5. Delayed Sparse Evidence

### Definition 9. Balanced Cue-Gap Task

A balanced cue-gap task samples a cue `q in {L, R}` with equal probability. The cue is visible before a gap. At decision time `D`, the correct optimal action depends on `q`, while the last `H` observations and supplied actions before the decision are identical across cues when `H < D`.

### Proposition 4. Finite Windows Shorter Than The Cue Gap Fail

In Definition 9, any decision rule using only the last `H` action-observation steps with `H < D` has cue-dependent decision accuracy at most `1/2` when the two cues require disjoint optimal actions.

**Proof summary.** The rule receives the same window for `L` and `R` trials, so it emits the same action distribution. Balanced cues with disjoint optimal actions make that shared decision correct for at most one cue class in expectation. Appendix Proposition A.4 gives the full proof.

**Paper interpretation.** The theorem applies to explicit finite windows and horizon-matched structured sequence spans. It does not forbid an unrestricted noise-free recurrent state from carrying a cue longer than the visible window.

## 7. Claims The Formal Package Does Not Make

- Counts are not claimed to be a complete biological model of path integration.
- Noncommutativity alone is not claimed to force sequence memory under full observations.
- Hybrid memory is not claimed to be universally optimal without a cost model.
- RNN, reservoir, and Lin-block comparisons remain mechanism-level empirical evidence.
