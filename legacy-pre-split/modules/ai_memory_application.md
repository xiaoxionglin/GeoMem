# AI Memory Application Module

## Role

The AI-agent track is a second test bed, not the main neuroscience claim. It should demonstrate that the same geometry-to-memory rule can guide artificial memory architectures.

## Proposed Mapping

- Metric planning tasks: vector or coordinate memory.
- Tool workflows with dependencies: graph memory.
- Nested goals and syntax-like tasks: stack or structured sequence memory.
- Long-horizon partially observable tasks: episodic and clone-state memory.
- Open-ended agent tasks: hybrid memory with geometry-sensitive routing.

## Claim

AI memory systems should not use one universal memory store. They should select or compose memory modules based on task geometry, input sparsity, and whether order matters.
