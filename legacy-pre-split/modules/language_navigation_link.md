# Language And Abstract Navigation Module

## Role Of Dyck Language

Dyck language should be used only as a limiting case. It cleanly demonstrates that nested, hierarchical structure requires stack-like memory, but it is not the central navigation model.

## Connection To GeoMem

The bridge between language and navigation is not that all navigation is language-like. The bridge is geometry:

- hierarchy and nesting create noncommutative histories;
- long-range dependency prevents local-state compression;
- stack-like memory becomes efficient when current state depends on the unresolved action history.

## Manuscript Rule

Dyck examples should appear after the main spatial argument, as an abstract-domain extension or boxed example.
