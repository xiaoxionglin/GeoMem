# Biological Mapping Module

## Computational Interpretation

This is not a one-to-one anatomical claim. The mapping should be stated as a computational interpretation:

- Entorhinal/grid/path-integration systems support local metric compression.
- Hippocampal relational and sequence systems support graph structure, context, route history, and aliasing.
- MEC input may help flexible replay and metric anchoring, while intrinsic hippocampal dynamics can preserve or generate sequence structure when raw sensory input is noisy or dense but the code reaching the sequence system has been sparsified.

## Main Biological Prediction

Sequence-like hippocampal dynamics should be more useful when current sensory input underdetermines state or when future behavior depends on route history. Path-integration/vector signals should be more useful when local metric updates are reliable and sufficient.
